Retail Sales Data Analysis

** Overview **

This project explores data from a retail sales dataset using SQL. It identifies
sales trends, evaluate discount effectiveness, and compares store performance.

** Tools Used **

- SQL
- Jupyter Notebook
- CSV Data
  
** Project Files **

- fSalesQueries.sql: SQL queries 
- Retail-Data.ipynb: Data cleaning 
- retail_store_sales_promotions_demand.csv: Retail sales dataset

** Business Questions **

Do discounts increase sales volume?
Which categories rely most on discounts?
Which stores perform best overall?
Which stores benefit the most from discounts?

** SQL Concepts **
JOIN
GROUP BY
SUM
COUNT
ORDER BY
Aggregate Functions

** Key Findings ** 

Compared sales performance with and without discounts
Measured discount dependence across product categories
Ranked stores based on revenue, units sold, and transaction volume
Generated business-focused insights from retail sales data
